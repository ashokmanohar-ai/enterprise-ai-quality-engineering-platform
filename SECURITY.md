# Security policy

Do not open public issues containing credentials, exploitable endpoint details, raw scanner reports, customer data, or production prompts. Report repository vulnerabilities privately through GitHub Security Advisories.

Run PyRIT, Garak, Promptfoo red-team, and AIPerf only against targets you own or have written authorization to assess. Define scope, rate, timing, contacts, stop conditions, and retention before execution. Use synthetic identities, accounts, policies, secrets, and evidence.

Supported code is the latest release on `main`. Dependency and model-provider behavior may change independently; consult `docs/COMPATIBILITY.md` before upgrades.
