# v1.0.0 — Enterprise AI Quality Engineering Control System

This first stable portfolio release presents one integrated control system for measurable LLM, RAG, agent and MCP quality. It is designed for AI Quality Engineer, AI Test Architect and LLM/RAG Evaluation Engineer review.

## Included evidence

- one canonical golden-case contract with native evaluation adapters
- DeepEval, Ragas and Promptfoo quality profiles with normalized findings
- agent trajectory, tool-use and MCP protocol/business-rule checks
- hard safety gates, baseline comparison and explicit deploy/block evidence
- Azure OpenAI configuration with offline-first, cost-controlled execution
- Phoenix-first observability and a production-to-regression feedback design
- a 66-second recruiter walkthrough and five-minute offline verification path
